# Incorporation

You use video to support learning. You keep teacher voice in charge.
Add video only when sure.
Sure means the title and description match the exact topic.
Use the duration to pick a clip, not to reject the video.

## 1 Sure Only Gate

Run three checks before you add a block.
You match the title to the lesson concept.
You match the description to the same operation.
You match the duration to the lesson time.
If any check fails you stop.
You teach with GNOS prose instead.

## 2 Where to Place

Place the video between the prediction step and the derivation step.
You complete setup before you show video.
You return to GNOS right after video.
You keep the lesson pace short.
You keep teacher voice leading.

## 3 Block Choice

You use a link block when you have not confirmed YouTube ID.
You use a full video block only after browser playback check.
You limit video to one per concept.
You never autoplay video.

## 4 Prompt and Check

You write a watch prompt for each block.
You tie the prompt to lesson symbols.
You add one follow up task in GNOS.
Treat watching as exposure, not as success.
You verify playback through the local HTTP server, never through `file://`.
See `embedding.md` for the Error 153 rule.

## 5 What to Record

You record eight items for each video.
You record the source title.
You record the Khan page URL.
You record the contentId.
You record the YouTube ID.
You record the duration.
You record the confidence.
You record the check date.
You record the placer name.
