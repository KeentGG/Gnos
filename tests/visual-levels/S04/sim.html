Model and assumptions

Model: X[i] ~ Uniform(0,1), i.i.d. draws in probability units. Count above = number of draws with X > threshold. Expected fraction above = 1 − threshold.

assumptions: draws are independent and identically distributed Uniform(0,1); the histogram uses 20 equal-width bins over [0,1]; the threshold line does not resample the data, only re-counts; reset restores threshold = 0.5 and n = 100 with a fresh sample. This simulation illustrates sampling variability, not empirical evidence for any real dataset.
