Model and assumptions

Independent Normal draws: mean 100 USD, standard deviation 15 USD. Each run adds 100 trials. Values are illustrative demand amounts.

Reset clears trials and restores the current seed. The same seed repeats the same sequence. Changing it changes the sample, while the distribution stays fixed.

Histogram: 5 USD bins from 40 to 160 USD, values outside this range remain in the statistics but are omitted from the plot. Dashed line: sample mean. Dotted line: model mean, 100 USD.
